Why it’s here

A 2.1 megacollab that never stopped being fun.

WOW is a 2.1 megacollab hosted by TrusTa, with Eggnog, Marwec, Pennutoh, Disp, SlimJim, Splash and ChaSe building parts. It is an XL level set to F-777's Space Battle, and it plays like the era it came from — bright, loud and unembarrassed.

Kandai verified it. It has drifted a long way down the Demonlist since, to #384, which says more about how much harder the top has become than about the level.
